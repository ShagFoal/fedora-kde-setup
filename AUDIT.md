# Проверка перед публикацией

Дата: 31 октября 2026, Asia/Almaty. Статус: локальная подготовка.

Проверены 13 файлов и фрагментов настроек с компьютера пользователя: шесть
конфигов терминала, два файла Dolphin, конфиг MPV, раскладки клавиатуры
и три фрагмента для повтора клавиш, выбранных сочетаний KDE и сетки столов.
Оригиналы не изменены. В копии `.zshrc` удалён блок `bm`, обновлён комментарий
`rebootw` и добавлены проверки наличия `efibootmgr` и режима UEFI.
В копии `dolphinrc` убрана привязка к цветовой схеме. Другие восемь полных
конфигов скопированы без изменений. Три фрагмента содержат только выбранные
группы/ключи исходных файлов; значения не придуманы и не заменены шаблонными.

Для Dolphin добавлены только `dolphinrc` и `kxmlgui5/dolphin/dolphinui.rc`.
Сохранены общие настройки, раскладка интерфейса и действие
`DoubleClickViewAction=go_up`: двойной щелчок по пустому месту поднимает на уровень
вверх. Цветовая схема и привязка к ней исключены по уточнению пользователя.
В этих файлах не обнаружены credentials, личные пути и история.
XML содержит меню, панель и сочетания клавиш. Закладки Dolphin
и общий список Places содержат ссылки на папки; их значения не выводились,
и эти файлы не копировались. История, сессии и настройки отдельных папок также
не включены. Тема/стиль KDE, значки и дополнительные плагины предпросмотра —
отдельные зависимости, которые установщик не восстанавливает.

MPV: `mpv.conf` скопирован без изменений. Сам MPV не добавлен в список пакетов
и не требуется для проверки установленной конфигурации. В исходном конфиге
включены сохранение позиции и истории; это флаги поведения, а не сами данные.
История, имена просмотренных видео, `watch_later`, сторонние скрипты и настройки
рядом с видео не переносились. Стандартный путь подтверждён
[руководством MPV](https://mpv.io/manual/stable/#configuration-files).

Клавиатура: `kxkbrc` перенесён целиком (US/RU, Caps Lock, WinClass).
Из `kcminputrc` сохранены только `RepeatDelay` и `RepeatRate` группы `[Keyboard]`.
Настройки курсора/мыши/тачпада исключены.
Из `kglobalshortcutsrc` отобрано 31 действие переключения рабочих столов
из группы `[kwin]`, включая отключённые сочетания, и только `_launch=Meta+Return`
из `[services][org.kde.konsole.desktop]`. Другие действия не экспортировались.
Текущие Meta+1/2/3 соответствуют столам №2/5/8; поэтому из `kwinrc` сохранены
ровно `Number=9` и `Rows=3` группы `[Desktops]`. UUID, размеры окон и эффекты
не копировались.

Установщик сливает три фрагмента с существующими файлами через
`scripts/merge-kconfig.py`, сохраняя остальные ключи, группы и комментарии.
Если клавиши выбранных действий заняты, освобождаются только конфликтующие
назначения. Остальные сочетания этих действий и их метаданные сохраняются.
Проверка `--check` сравнивает только выбранные значения. Активация сохранённых
настроек KDE предусмотрена после нового входа в Plasma; текущий сеанс, D-Bus,
сервисы и реальные сочетания клавиш во время подготовки не менялись.

Настройки и стили отображения папок разделяются в
[документации Dolphin](https://docs.kde.org/stable_kf6/en/dolphin/dolphin/configuring-dolphin.html).
Путь `kxmlgui5` сохранён и для KF6 в
[KDEInstallDirs6](https://api.kde.org/ecm/kde-module/KDEInstallDirs6.html).

Шаблонный поиск не обнаружил узнаваемых API-ключей, токенов, приватных ключей,
паролей в присваиваниях, URL с credentials, email и персональных абсолютных путей.
Ручной просмотр показал только настройки оболочки, prompt, терминала,
Fastfetch, Dolphin, MPV и выбранные параметры клавиатуры/KDE.
Проверка по шаблонам не гарантирует обнаружение произвольного секрета.

`.gitconfig`, credentials, history, `.env`, SSH/GPG, `backup-main`, Restic/Rclone,
посторонние KDE-файлы, лишние профили/схемы и `.bak` не копировались.
`.gitignore` разрешает только точный список подготовленных файлов.

Загрузки зафиксированы в `dependencies.tsv`. SHA-256 архивов
[Starship 1.27.0](https://github.com/starship/starship/releases/tag/v1.27.0),
[Patina 1.11.0](https://github.com/michel-kraemer/zsh-patina/releases/tag/1.11.0) и
[Nerd Fonts 3.5.1](https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1)
сверены с digest официальных GitHub Releases.
Хеши извлекаемых бинарных файлов/шрифтов дополнительно рассчитаны после проверки
архивов. Autosuggestions зафиксирован на commit
`85919cd1ffa7d2d5412f6d3fe437ebdbeeec4fc5`; его файл и LICENSE получены по HTTPS
из официального репозитория, их SHA-256 записаны при подготовке.

Проверки завершены успешно:

- `bash -n install.sh`, `zsh -dfn files/.zshrc`, аудит точного списка из 22 файлов,
  разбор XML/INI Dolphin, действие двойного щелчка по пустому месту,
  отсутствие привязки к цветовой схеме и контрольные суммы.
  Исходные 13 файлов повторно проверены по SHA-256: без изменений.
- `./install.sh --dry-run` на текущей Fedora 45 x86_64: без установки пакетов и
  замены конфигов; показаны отличающаяся копия `.zshrc` и план зависимостей.
- 19 изолированных тестов для обновлённого набора из 13 файлов/фрагментов: backup с сохранением прав/времени,
  повторный запуск без загрузок и sudo, ошибочная загрузка, ссылки в путях и архиве,
  лишние пути архива, изменённые контрольные суммы, custom XDG/ZDOTDIR,
  проверка без записи, удаление репозитория после установки и скрытие значения
  синтетического токена в сообщении аудита. Новые проверки подтвердили сохранение
  посторонних сочетаний, настроек мыши и параметров окон при слиянии; сохранение
  личных правок вне выбранных ключей при повторной установке; backup изменённого
  выбранного сочетания; обработку вложенных групп KConfig и конца файла без LF.
  Подставной установщик пакетов проверяет, что пакет MPV не запрашивается.
  Отдельный тест проверяет освобождение Meta+D/Meta+Return и других конфликтов
  с сохранением альтернативных сочетаний и экранированных запятых.
- Настоящие x86_64-бинарники Starship и Patina запускаются с `--version`;
  Starship формирует prompt с данным TOML без ошибок. Autosuggestions и Starship
  загружаются в Zsh с временным HOME, `bm` отсутствует. В этом тесте активация
  Patina заменена пустой командой, чтобы не запускать демон. Настоящий вывод
  `patina activate` отдельно прошёл синтаксическую проверку Zsh без выполнения.
- `fc-scan` подтвердил семейство `JetBrainsMono Nerd Font`; Fastfetch прочитал
  подготовленный конфиг без ошибок. Внешний вид KDE/Konsole/Dolphin не проверялся.

Полная установка пакетов и смена живых настроек на этой системе не выполнялись.
На чистой Fedora установщик ещё не запускался. Konsole и Dolphin визуально не проверялись.
Реальное переключение раскладок/рабочих столов и Meta+Enter на чистой KDE
не проверялись; подтверждены содержимое файлов и безопасное слияние.
Для aarch64 проверены официальные архивы и хеши, выполнение не проверялось.
`rebootw` не вызывался, параметры UEFI не менялись.

Создан локальный Git-репозиторий с веткой `main`, без staging, коммита и remote.
Ничего не отправлялось на GitHub.
