# После переустановки: настроить Plasma вручную

Эти значения прочитаны из текущей системы. Скрипт не копирует и не изменяет
`kxkbrc`, `kcminputrc`, `kglobalshortcutsrc` или `kwinrc`.

1. В настройках клавиатуры добавь **English (US)** и **Russian**.
   Переключение — **Caps Lock**. Раскладка запоминается по классу приложения
   (`WinClass`). Повтор клавиш: задержка **250 мс**, скорость **20 повторов/с**.
2. Создай **9 виртуальных рабочих столов**, расположение — **3 строки**.
3. Назначь переключения столов по таблице ниже.
4. Для запуска **Konsole** назначь **Meta+Enter** (`Meta+Return`).

| Клавиши | Действие |
|---|---|
| Meta+A, также Meta+Ctrl+Left | стол слева |
| Meta+D, также Meta+Ctrl+Right | стол справа |
| Meta+Ctrl+Up / Meta+Ctrl+Down | стол сверху / снизу |
| Meta+1 / Meta+2 / Meta+3 | стол №2 / №5 / №8 |

В исходной конфигурации прямые переходы на остальные столы не назначены.
Если Meta+D занято действием «Показать рабочий стол», освободи его для перехода
вправо. Остальные сочетания, темы, значки и оформление настрой самостоятельно.

Настройки Dolphin и Konsole восстанавливаются через ссылки на Main.
